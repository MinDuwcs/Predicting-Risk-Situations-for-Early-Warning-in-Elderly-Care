CRITICAL #2 — SMOTE placement fix (within-fold, not before split)
Deviation from original notebook methodology

Original notebook: Applied SMOTE to entire dataset (499→9,501) BEFORE train/test split. This means synthetic samples generated from the same minority records appear in both train and test → optimistic metrics.

Phase 1 fix: SMOTE applied ONLY inside each CV fold's training set. Test/validation folds always use original data.

  • This is the methodologically correct approach per the imbalanced-learn documentation
  • Expected result: metrics will drop significantly — this is honest, not a regression
